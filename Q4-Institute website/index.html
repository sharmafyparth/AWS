C Programming Tutorial

Introduction to C

C is a general-purpose programming language widely used for system programming and application development.

Basic C Program

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

Important Topics

  1. Variables and Data Types
  2. Operators
  3. Conditional Statements
  4. Loops
  5. Arrays
  6. Functions
  7. Pointers

Example

The following program adds two numbers: 

#include <stdio.h>

int main()
{
    int a = 10;
    int b = 20;

    int sum = a + b;

    printf("Sum = %d", sum);

    return 0;
}
